# JobHunter User Guide

## Introduction

JobHunter is a desktop application designed to streamline the job hunting process. It provides a centralized platform for tracking job applications, managing related documents, and organizing your job search efforts.

## Installation

1. Download the latest release of JobHunter from the releases page.
2. Move the JobHunter.app file to your Applications folder.
3. Open JobHunter from your Applications folder.

## Getting Started

### Main Interface

Upon launching JobHunter, you'll see the main interface which consists of:

1. **Job List**: A table showing all your job applications with key information.
2. **Filter Bar**: Tools to filter and search your job applications.
3. **Action Buttons**: Buttons to add, edit, or delete job applications.
4. **Detail View**: A panel showing detailed information about the selected job application.

### Adding a New Job Application

1. Click the "Add Job" button (or use ⌘+N).
2. Fill in the job details in the form that appears:
   - Company Name
   - Job Title
   - Application Date (defaults to today)
   - Application Deadline (if applicable)
   - Status (Applied, Interviewing, Rejected, Offer)
   - Job Description (text or URL)
   - Notes
   - Contact Information
3. Click "Save" to add the job application to your list.

### Attaching Documents

1. Select a job application from the list.
2. In the detail view, click "Attach Document".
3. Select a PDF file from your computer.
4. The document will be linked to the selected job application.

### Viewing Attached Documents

1. Select a job application with attached documents.
2. In the detail view, you'll see a list of attached documents.
3. Click on a document to open it in your default PDF viewer.

### Editing a Job Application

1. Select the job application you want to edit.
2. Click the "Edit" button (or use ⌘+E).
3. Modify the job details as needed.
4. Click "Save" to update the job application.

### Deleting a Job Application

1. Select the job application you want to delete.
2. Click the "Delete" button (or use ⌘+Delete).
3. Confirm the deletion when prompted.

### Filtering and Searching

1. Use the search field to search for jobs by keywords in the title, company name, or notes.
2. Use the status dropdown to filter jobs by status (All, Applied, Interviewing, Rejected, Offer).
3. Use the date range pickers to filter jobs by application date or deadline.

### Exporting and Importing Data

1. To export your data, go to File > Export and select your desired format (CSV or JSON).
2. To import data, go to File > Import and select a previously exported file.

## iCloud Integration

JobHunter automatically syncs your data across all your macOS devices using iCloud:

1. Ensure you're signed in to iCloud on all your devices.
2. Your job applications and attached documents will be synced automatically.
3. Changes made on one device will appear on all your other devices.

## Keyboard Shortcuts

- **⌘+N**: Add a new job application
- **⌘+E**: Edit the selected job application
- **⌘+Delete**: Delete the selected job application
- **⌘+F**: Focus the search field
- **⌘+,**: Open preferences
- **⌘+Q**: Quit JobHunter

## Troubleshooting

### Data Not Syncing

1. Ensure you're signed in to iCloud on all devices.
2. Check your internet connection.
3. Wait a few minutes for iCloud to sync.

### Attached Documents Not Opening

1. Ensure you have a compatible PDF viewer installed.
2. Check that the file path is still valid.
3. Try reattaching the document.

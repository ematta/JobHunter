## Installation

To install JobHunter:

1. Download the latest release from our website or GitHub repository
2. Move the .app file to your Applications folder
3. Double-click to launch

## Getting Started

After installation:

1. Launch JobHunter from your Applications folder
2. Start tracking your job applications using the "Add Job" button
3. Organize your job search with filters and search functionality
4. Attach resumes and other documents to your job applications

See the [User Guide](UserGuide.md) for more detailed instructions.

## Troubleshooting

If you encounter issues:

1. Check the [User Guide](UserGuide.md) for help with common problems
2. Visit our GitHub repository to report issues
3. Contact support at support@jobhunter.app
